# Pong - Multiplayer Game

Welcome to the **Pong Multiplayer Game!** This project is a modern implementation of the classic Pong game, built using Unity and Netcode for GameObjects. This repository contains the source code and assets required to play and experiment with a multiplayer version of Pong.

## Features

- **Multiplayer Support:** Built using Netcode for GameObjects, enabling two players to compete in real-time.

- **Smooth Synchronization:** Seamless movement and input synchronization between host and client.

- **Customizable Gameplay:** Modify paddle speed, ball speed, and other game settings to create your own experience.

- **Minimalist Design:** Clean and simple UI for an enjoyable and distraction-free experience.

## Getting Started

Follow these instructions to set up the project locally and start playing:

## Prerequisites

- Unity 2022.3.47f1 (or later)

- Netcode for GameObjects package installed via Unity Package Manager

- Git (optional, for cloning the repository)

## Cloning the Repository
```bash
git clone https://github.com/namruthagude/Pong.git
cd Pong
```

## Opening in Unity

1. Launch Unity Hub.

2. Click on Add Project and navigate to the folder where you cloned this repository.

3. Open the project in Unity Editor.

## Gameplay

1. Launch the game in the Unity Editor or build it for your platform.

2. One player acts as the **Host** while the other joins as a **Client**.

3. Control the paddles using keyboard inputs.

4. The first player to score a set number of points wins the match!

## Dependencies

1. This project uses the following Unity packages:

2. Netcode for GameObjects: A networking library for building multiplayer games.

3. Input System: Modern input handling for Unity.

## Setup Instructions

1.Install the required Unity version (2022.3.47f1 or later).

2.Clone this repository and open it in Unity.

3.Install the **Netcode for GameObjects** package via Unity Package Manager:

  - Go to **Window > Package Manager**.

  - Click + > **Add package by name....**

  - Enter `com.unity.netcode` and click **Add**.

4.Test the game in the Editor by running two instances: one as the host and the other as a client.
